## 2. 구현 요지

**오늘의 글리프 워터마크** — 오늘 일진의 천간(`stem`)을 `getMyTodayCard`가 반환하는 `note.stem`으로 받아, 기존 `ArchetypeGlyph` 컴포넌트(10개 천간별 SVG 세트, `GLYPHS: Record<TenStem, ReactNode>`)에 그대로 전달했다. `TenStem`이 이미 글리프 맵의 키이므로 중간에 별도 아키타입 조회 코드를 추가하지 않았다. 핵심 문장 `<p>` 뒤(`z-index: 0`, 문장은 `z-index: 1`)에 절대 위치로 배치, 크기 180px, `opacity: 0.07`, 색은 오늘의 오행 fg 색(`ELEMENT_COLORS[element].fg`), `aria-hidden="true"` + `pointerEvents: none`로 순수 장식임을 명시했다. 모션 없음(정적 렌더).

**AHEAD 오행색 + 문장 변주 충돌 방지** — 날짜 라벨 앞에 그 날 `dayElement`의 오행색 점(6px)을 추가하고, 라벨 텍스트 색도 동일 색으로 바꿨다(기존 회색 대신). 두 AHEAD 카드가 같은 관계(`rel`)이고 `pickVariant` 결과 문장까지 우연히 같으면, 두 번째 카드만 같은 풀에서 `(기존 인덱스+1) % 풀 길이`로 다음 문장을 선택하도록 했다 — 풀 길이가 1이면 자연히 그대로 유지된다(변경 없음).

**Do/Don't 아이콘 + 점 크기** — 기존 `DoIcon`/`DontIcon`(14px)을 라벨 앞에 복귀시켰다. 사람 행의 오행색 점을 8px에서 10px로 키우고 이름과의 수직 중앙 정렬은 그대로 유지했다.

카피 문구·위계·다른 화면은 일절 건드리지 않았다.

## 3. 대비(가독성) 실측

글리프 워터마크가 배경에 섞여도 문장 대비를 해치지 않는지, 가장 진한 오행색(fire, `#C4502E`)을 최대 불투명도(0.08)로 종이색(`#F1EDE6`) 위에 얹었을 때의 배경 변화(≈`rgb(237,224,215)`)와 잉크색(`#1A1815`) 텍스트 사이 WCAG 대비비를 계산한 결과 **약 13.7:1**로, 기준(4.5:1)을 훨씬 상회한다.

## 4. 렌더 확인 — 2장 (실제 브라우저, Playwright, 430px 폭)

텔레그램으로 **전송함**.

1. 한국어 홈 — 오늘 문장 배경에 대형 글리프(마름모형, 은은하게 비침)와 AHEAD 카드의 오행색 점(초록/주황)이 보이는 것을 확인.
2. 같은 화면 AHEAD 섹션 — 실제 프로필(1990-06-02생, earth)로 오늘(2026-08-05) 기준 조회 시 두 AHEAD 카드가 **자연스럽게 같은 관계(today_nurtures)**로 나왔고, 문장 변주 로직이 실제로 서로 다른 문장("기운이 나를 밀어주는 날이에요..." / "순풍이 부는 날 — 오늘은 기대도 괜찮아요.")을 렌더한 것을 확인 — 단위 테스트 목이 아닌 실제 계산 경로에서 충돌 방지 로직이 작동함을 검증.

## 6. 정직 보고

- 대비비는 opacity 블렌딩을 수식으로 계산한 값이다. 실제 기기의 색 렌더링(디스플레이 감마, 서브픽셀 등)과 완전히 동일하지는 않을 수 있으나, 여유폭(13.7 vs 4.5 기준)이 커서 실사용에서 문제가 될 가능성은 낮다고 판단했다.
- AHEAD 변주 충돌 방지는 "같은 rel + 같은 문장"일 때만 개입하므로, 두 카드의 rel 자체가 다르면(예: 하나는 `same`, 하나는 `today_nurtures`) 여전히 우연히 비슷한 톤의 문장이 나올 수 있다 — 이는 브리프 범위(문장 자체가 동일한 경우만 방지) 밖이라 손대지 않았다.
